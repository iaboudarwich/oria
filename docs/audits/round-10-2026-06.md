## Architectural decisions honored

- **Two AI roles, never confused.** Infrastructure (extraction, classification,
  embeddings, summarization, onboarding synthesis, sidecar) stays pinned to
  Oria's Anthropic key. Conversation (Ask Oria, work agent) routes through the
  user's connected provider, else Oria.
- **One connection per user** (UNIQUE on user_id). Switching is disconnect +
  reconnect.
- **Provider memory is the provider's.** Oria syncs nothing; context-sharing
  happens in the query payload (Oria's retrieved sources + personalization), so
  the user's AI sees Oria's structured knowledge alongside its own memory.
- **Voice (Whisper) and the sidecar stay on Oria's keys**; provider abstraction
  lives only in the Next.js layer.
- **Anthropic is the deepest path** (Oria's backend already runs on it); OpenAI
  and Gemini are fully wired and adapter-thin, to be perfected in later rounds.

## Migration status of existing AI call sites

- **Conversation (migrated):** Ask Oria (lib/ai/agent.ts) and the work agent
  (lib/ai/work-agent.ts) stream through streamConversation -> the abstraction.
- **Infrastructure (stays on Oria's Anthropic, by design):** 18 lib files still
  call getAnthropic directly (extraction, doc/field/image classification,
  section inference + suggestions, trackable detection, Gmail + calendar
  classification, cloud-file summary). Pinned to Anthropic; no BYO. Migrating
  them onto getProvider(userId, "infrastructure") would return the same
  Anthropic client, so it is deferred as pure churn with no behavior change.
- **Onboarding conversation + reshape generation stays on Oria** (the round's
  stated decision: onboarding must work before a key is set).
- **Small user-triggered calls** (sort-items, suggest-entity-schema, field
  translation) stay on Oria's Anthropic for now; they are not the core
  conversation surface and BYO value there is marginal. Deferred, documented.

## Deferred, and why

- **OpenAI/Gemini polish.** Both adapters are wired and validated but thin (no
  tool-use translation, no vision); the round scopes deep polish to later. Tool
  calls are not used by the conversation surfaces today.
- **Provider-native embeddings are not wired into Oria's store.** Oria's vector
  store is 384-dim (sidecar MiniLM); OpenAI (1536) / Gemini embeddings differ in
  dimension, so adapter.embed() exists for completeness but never feeds
  retrieval. (The spec's "Voyage" embedding is not used anywhere in the repo.)

## Performance (per provider)

Ask Oria latency depends on the answering model, which now varies by connection.
Measured from this environment is not possible (no authenticated production
browser, same constraint as docs/perf/2026-06-baseline.md). Static expectation
to capture in production:

- **Oria default (Anthropic, fast tier = Haiku):** the existing baseline; lowest
  time-to-first-token.
- **User Anthropic (BYO):** same model family; comparable, plus the user key's
  own rate posture.
- **User OpenAI (gpt-4o-mini):** comparable fast-tier latency; first-token
  similar.
- **User Gemini (gemini-1.5-flash):** comparable; regional routing may add
  variance.

No render-path regression was introduced; the streaming shape is unchanged.

## Smoke-test checklist

1. Settings -> AI: connect Claude with a real key; the assisted modal validates
   and the state card shows "Claude is powering Ask Oria."
2. Ask a question; the answer streams from the user's Anthropic key; the
   powered-by line reads "Powered by your Claude."
3. Disconnect (confirm modal); Ask switches back to Oria's default; the line
   reads "Powered by Oria's default AI."
4. Connect ChatGPT, then Gemini; each answers Ask Oria. Paste an invalid key;
   the modal shows a clear error and nothing is saved.
5. Force a runtime key failure; the next query silently falls back to Oria and a
   one-time toast appears, linking to Settings -> AI; it does not repeat.
6. New-user onboarding shows the "Connect your AI" card; skip works; connecting
   mid-onboarding works and the conversation itself is unaffected.
7. Locale switch (ar/fr/es) shows translated AI copy throughout.
